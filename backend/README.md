# 🚗 PUC Booking Platform

A full-stack **MERN-based vehicle compliance platform** that enables vehicle owners to book on-site PUC (Pollution Under Control) inspections, allows certified inspectors to manage nearby bookings, supports online and COD payments, and maintains complete booking and compliance history.

## 📌 Problem Statement
In many regions, vehicle owners face inconvenience in obtaining valid PUC certificates due to:

- Limited PUC centers
- Lack of doorstep inspection services
- No centralized digital booking or tracking system

This platform digitizes and simplifies the **PUC compliance workflow** by connecting vehicle owners with nearby inspectors through a role-based, location-aware booking system.

---

## 🎯 Key Features

### 👤 Vehicle Owner (User)
- Secure authentication & login
- Add and manage vehicles
- Book PUC inspection at preferred location
- Choose payment mode (Online / COD)
- Track booking status in real-time
- View previous booking & PUC history
- Download PUC certificate after completion

### 🧑‍🔧 PUC Inspector (Checker)
- Secure role-based login
- View nearby bookings using location-based filtering
- Accept and manage assigned bookings
- Update inspection status (In Progress / Completed)
- Upload PUC certificate
- View completed inspections history

### 🛠️ Admin
- Manage users and inspectors
- Monitor bookings and payments
- View platform-level analytics

---

## 🏗️ System Workflow

User Booking -> Booking Created -> Checker Assigned (Auto) -> Inspection In Progress -> PUC Certificate Generated -> Payment Completed -> Booking Marked as Completed
